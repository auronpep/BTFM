# Google Stitch Prompt Pack

Use these prompts to generate visual concepts. Stitch output should be treated as design reference. Production code should be rebuilt in Astro using the project design system.

## Global Design Constraints

Use these constraints with every prompt:

```text
Design a serious, warm, editorial website for a nonprofit board training resource published by a nonprofit law firm. It should feel practical, credible, and educational, not like a generic law firm landing page. Use deep navy, firm slate, warm paper, soft stone, muted gold, and a restrained teal accent. Use readable serif headings and clean sans-serif body text. Avoid decorative gradients, oversized marketing sections, and hard-to-read script for important text. The site must support four actions: read articles, learn about board training, register for a webinar or request in-person training, and visit NPOlawyers.com.
```

## Homepage Concept Prompt

```text
Create a desktop and mobile homepage for "The Principles of Board Training", a free nonprofit board training resource from California Center for Nonprofit Law. The product concept is "The Boardroom Field Manual." The first viewport should say "Board service gets serious when the organization gets serious." The audience is working California nonprofit board members who are already reviewing budgets, reading executive reports, managing risk, and making decisions that need to hold up later. Include clear actions: Prepare for Your Next Board Meeting, Open the $3M Board Member Guide, Request Board Training, Register for a Webinar, Visit NPO Lawyers. Below the hero, include a boardroom problem picker, Strategy/Safety/Audit module, featured tools, featured scenarios, training CTA, and legal-help CTA. Use imagery related to board packets, agendas, minutes, budget reports, audit checklists, and governance documents.
```

## Next Meeting Prompt

```text
Create a "Prepare for Your Next Board Meeting" page for a nonprofit board training site. The page should let the user choose what is on the agenda: Budget approval, Audit or Form 990, Executive director report, Compensation, Conflict of interest, Insurance or safety, Bylaws or policy changes, Difficult board member issue, Annual meeting. Each card should preview what to read before the meeting, what to ask, what documents matter, what minutes should show, and when to call counsel. The design should feel like a boardroom field manual, not a blog.
```

## Tools Lab Prompt

```text
Create a tools landing page for a boardroom field manual. Include Board Packet Lab, Board Question Bank, Board Red Flags, Mature Board Self-Assessment, $3M Board Member Checklist, Board Packet Review Sheet, Audit Committee Readiness Checklist, Budget Deviation Worksheet, Minutes Quality Scorecard, Board Authority Map, and Annual Governance Calendar. Make the tools feel practical and high-status, like documents a serious board member would use before a meeting.
```

## Article Page Prompt

```text
Create a long-form article page for a nonprofit board training website. The article title is "What Does a Nonprofit Board Actually Do?" The page should include category, reading time, updated date, article body, sticky or inline table of contents, related downloads, related scenarios, and a sidebar CTA for webinar training. Add a subtle educational disclaimer near the bottom. The reading experience should be calm, spacious, and highly legible on desktop and mobile.
```

## Scenario Page Prompt

```text
Create a scenario article page for nonprofit board training. Scenario title: "The Founder Wants the Board to Approve Her Salary." Structure the page with sections for Facts, The Board Issue, What the Board Should Ask, Recommended Board Action, Related Template, and Training CTA. The design should make the scenario feel practical and real, with callout boxes for risk and board action. Avoid legal intimidation. Keep it credible and clear.
```

## Downloads Library Prompt

```text
Create a downloads library page for a nonprofit board training resource. Include filters for Board Meetings, Fiduciary Duties, Startup Governance, Financial Oversight, Safety and Risk, and Annual Compliance. Show download cards for Board Meeting Agenda Template, Board Minutes Template, Annual Board Calendar, First Board Meeting Checklist, Conflict of Interest Annual Disclosure, Budget Review Worksheet, Safety Review Checklist, and Policy Book Starter Index. Cards should look like practical files and show related articles.
```

## Training Page Prompt

```text
Create a training program page for a law firm that offers free webinars and paid in-person nonprofit board training. The page should describe who the program is for, what boards learn, sample modules, webinar registration, in-person training inquiry, and relationship to NPOlawyers.com. Include modules: Board Duties, Board Meetings, Strategy Safety Audit, Financial Oversight, Conflicts and Compensation, Annual Meeting. Keep the design professional and conversion-focused without making the free resource feel like bait.
```

## Mobile Navigation Prompt

```text
Create a mobile navigation pattern for this site. It must expose Articles, Boards 101, Scenarios, Downloads, Training, and NPO Lawyers. Include a persistent high-priority Training button and readable tap targets. Make it accessible, simple, and credible.
```

## Design Critique Prompt

```text
Critique this generated design for a nonprofit board training website. Check whether the four primary actions are obvious, whether the site feels educational rather than salesy, whether typography is readable, whether the palette feels credible and not one-note, whether the homepage supports real article/download content, and whether mobile users can quickly choose where to go.
```
