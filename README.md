# CDX

Planning workspace for a nonprofit board training website and resource library published in connection with the California Center for Nonprofit Law / NPO Lawyers.

The current project materials are in `docs/`.

## Planning Documents

- `planning/DESIGN_IMPLEMENTATION_PLAN.md` - boss-ready design, content, UX, and implementation plan.
- `planning/PARALLEL_WORK_PLAN.md` - worker split, branch ownership, merge order, and definition of done.
- `planning/HOSTINGER_DEPLOYMENT_PLAN.md` - static-first Hostinger deployment plan.
- `planning/TOOLING_RECOMMENDATIONS.md` - Codex, Claude Code, Google Stitch, Figma, Copilot, and connector recommendations.
- `planning/STITCH_PROMPTS.md` - prompts for generating concept screens in Google Stitch.
- `planning/COMPETITION_REVIEW_PACKAGE.md` - scorecard and pitch notes for comparing this proposal against competing submissions.
- `tasks/todo.md` - task tracking and setup notes.

## Recommended Build Direction

Use Astro static output with MDX/content collections, deploy generated `dist/` files to Hostinger, and keep source in the private GitHub repository.
